# Avatar

A person's initials in a circle.

## Markup
```html
<span class="avatar">AM</span>
```

## In React
`import { Avatar } from '../src'`, from `src/components/Avatar.tsx`. It renders the markup above.
```tsx
<Avatar initials="AM" />
```

## Variants and states
None.

## Use for
- A person in a row or list

## Never
- A product logo (no check yet)

## Lives in
Table cells, list items.
