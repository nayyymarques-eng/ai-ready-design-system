Halden Pharmacy: proof at handover

Halden sends some medicines that may only go to an adult. With the ID check on, the driver scans the customer's ID for those parcels and records the year of birth only, not the ID number.

Parcels that need a signature or an ID check always come back to the depot.

Start date

Applies to every Halden Pharmacy delivery scheduled on or after this date. Deliveries already on a route keep the current rules.
