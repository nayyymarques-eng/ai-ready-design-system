# Numeral

A count next to a label.

## Markup
```html
<span class="numeral">24</span>
```

## In React
`import { Numeral } from '../src'`, from `src/components/Numeral.tsx`. It renders the markup above.
```tsx
<Numeral>24</Numeral>
```

## Variants and states
None.

## Use for
- A count in the nav or next to a title

## Never
- A badge for a count (checked by NUM-01)

## Lives in
Nav items, section titles, tabs, toggle items.

## Tokens
--type-small, --muted

## Checked by
NUM-01
